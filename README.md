# Mariah

Static responsive landing page based on the shared Figma node thumbnail.

## Preview

Open `index.html` in a browser, or serve the folder with any static file server:

```sh
python3 -m http.server 4173
```

Then visit <http://localhost:4173>.

## Design source

The public Figma page did not expose structured MCP design resources in this
environment, so the implementation uses the node-specific public thumbnail as a
visual reference and local asset.
